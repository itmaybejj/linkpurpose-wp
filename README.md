# Link Purpose Icons for WordPress

WordPress port of the [Link Purpose Icons Drupal module](https://www.drupal.org/project/linkpurpose), wrapping the [Link Purpose JS library](https://itmaybejj.github.io/linkpurpose/): visible icons and screen-reader hints for links that open new windows, leave the site, download files, send email, make calls or open apps.
